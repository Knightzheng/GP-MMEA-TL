# Runs Layout

- experiments/baseline/: baseline-related training runs
- experiments/tmmeada/: TMMEA-DA-related training runs
- experiments/gpu_peak_minimal/: minimal formal GPU peak-memory supplement runs
- experiments/README.md: guide to current experiment-run directories and their mainline-vs-support roles
- transfer/: cross-dataset transfer runs
  - transfer/README.md: official 4-target transfer run roots and how to distinguish formal runs from exploratory runs
- system/: queue logs, temporary configs, templates

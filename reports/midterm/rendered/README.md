# 中期模板目录说明

本目录只用于存放学校下发的中期报告模板与填写说明，不再保留上一线程自动生成的中期报告成品。

## 当前应保留的文件

- `附件1：中期报告.doc`
  - 学校原始中期报告模板，后续 `docx/pdf` 必须严格按此版式生成。
- `附件2：中期报告填写参考说明.doc`
  - 学校填写要求说明。

## 已确认的模板要求

1. 前一阶段工作总结：不少于 `400` 字。
2. 下一阶段工作计划：不少于 `300` 字。
3. 存在问题：不少于 `100` 字。
4. 指导教师意见：必须评价完成情况、指出问题并提出改进建议。
5. 此表需要双面打印。

## 字段核对

模板正文包含以下字段：

- 日期
- 学号
- 姓名
- 班级
- 联系电话
- 电子邮箱
- 实习单位
- 设计（论文）题目
- 前一阶段工作总结
- 下一阶段工作计划
- 存在问题
- 其它
- 指导教师意见

## 目录约束

1. 未经人工核对，不要在本目录重新放入自动生成的 `docx`、`pdf` 或“教师意见参考版”成品。
2. 如果后续要导出正式版，必须基于新的、已核实的中期正文生成。
3. 模板说明与生成结果应分离；当前目录优先保持为“模板原件目录”。

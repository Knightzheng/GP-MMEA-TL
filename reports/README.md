# Reports Layout

- baseline/: baseline summary and aggregate outputs
- tmmeada/: TMMEA-DA summaries, sweeps, ablations
- epoch3/: epoch3 pilot/formal compare artifacts
- epoch10/: epoch10 pilot/tuning compare and decisions
- transfer/: source->target transfer artifacts and run cards
  - transfer/README.md: current official transfer result entry points and how to treat historical exploration files
  - transfer_gpu_peak_minimal_summary.md/.csv: supplementary minimal GPU-peak-memory measurements for representative target-adapt settings
- midterm/: midterm draft/submission documents
- planning/: next-stage plans and auto decisions
- notes/: technical notes and overnight summaries
- notes/thread_sync_shared.md: shared handoff board between thesis-writing thread and project-optimization thread
- notes/taskbook_gap_assessment_20260315.md: taskbook/proposal/mainline closure assessment and current gap audit
- notes/mainline_traceability_matrix_20260315.md: taskbook/proposal requirements mapped to formal results, scripts, and run directories
- notes/mainline_closure_onepage_20260315.md: one-page defense/acceptance summary of what is already complete in the mainline and what remains auxiliary
- compare/: cross-method compare tables
- tmp/: temporary intermediate outputs
- misc/: uncategorized artifacts
